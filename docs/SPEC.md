# Specification — my-portfolio

- Version: 0.1 · 2026-10-13
- Status: draft

## 1. Context and vision

I created this portfolio to showcase my projects, share my ongoing tech watch, and highlight my skill set. Download my CV directly from the site or use the contact section to drop a message—I’d love to connect!

The ProblemA static CV lists skills but doesn't prove them. It lacks context on how I actually write code, solve problems, and keep up with new technologies.The VisionTo create an interactive platform that transforms abstract qualifications into concrete proof of work.
