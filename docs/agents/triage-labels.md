# Triage labels

Agent workflows use five triage roles, mapped here to the repository's actual labels.

| Role              | Label             | Meaning                             |
| ----------------- | ----------------- | ----------------------------------- |
| `needs-triage`    | `needs-triage`    | To be assessed by a maintainer      |
| `needs-info`      | `needs-info`      | Waiting for information             |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent |
| `ready-for-human` | `ready-for-human` | Needs a human implementation        |
| `wontfix`         | `wontfix`         | Will not be addressed               |

These labels describe the **workflow state**; other labels (type, domain, priority) describe the nature of the issue.
